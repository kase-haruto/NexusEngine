# エディタ環境設定

「編集 > 環境設定」からカテゴリを選択する。

- 一般: 言語、テーマ、文字サイズ、UI 倍率、レイアウトの自動保存。
- レベルエディタ: トランスフォームギズモの表示、ビューポートの起動時の既定表示。
- レンダリング: GI の方式（オフ、DDGI、RTGI、ベイク済み）。

GI は既定でオフ。変更は次の描画から反映され、プロジェクトの
`Config/Editor.settings` の `giMode` に保存される。レベルの切り替えと
エディタ内の再生にも同じ選択を適用する。不明な値はオフとして扱う。
DDGI / RTGI は DXR 対応 GPU、ベイク済みはそのレベルのキャッシュが必要。
オフでも環境光と IBL は使用できる。

一般設定は従来通り個人設定に保存する。ビューポートの起動時設定は
個人のパネル表示状態が保存されている場合、その状態を優先する。
レンダラ診断画面で GI 品質やベイクを操作できるが、方式の選択は環境設定で行う。
