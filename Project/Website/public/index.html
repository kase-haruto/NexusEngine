01 / ABOUT THE ENGINE

つくる。試す。
中身まで理解する。

NexusEngineは、ツール・エディタ・グラフィックス・フィジックスを学ぶために開発しているゲームエンジンです。実行環境と制作ツールをつなぎ、各機能の責務と拡張性を大切にしています。

01 — LANGUAGE

言語を選び、組み合わせる。

C++、C#、両方を使うHybridプロジェクト。ECS・Level・Reflectionを共有し、同じWorldでゲームロジックを構築します。

C++C# / MonoHybrid
02 — WORKSPACE

編集から実行まで。

EditorとRuntimeを分離した構成。共通のDetailsでプロパティを編集し、Level保存やUndo / Redo、Playでの動作確認につなげます。

EditorLevelReflection
03 — GAMEPLAY

ゲームの基礎をつなぐ。

DirectX 12描画、Jolt Physics、WAVオーディオ、キーボード・マウス入力。1.1.1ではXInputゲームパッド入力も追加しています。

DirectX 12PhysicsInput / Audio

    ランチャーをインストール

06 / BEFORE YOU BUILD

開発前に、確認を。

開発中のエンジンです。対応範囲と制約を確認し、移行前にプロジェクトをバックアップしてください。

開発環境

Windows x64、DirectX 12に対応するGPU。ゲームプロジェクトのビルドにはVisual Studio C++ v145ツール、Windows SDK、.NET SDKが必要です。Monoプロジェクトには公式Mono x64 SDKを用意し、NEXUS_MONO_ROOTまたはNexusMonoRootを設定します。

ランチャーは自己完結型です。開発用SDKの準備とは別にインストールできます。プロジェクトは短いパスへの配置を推奨します。

現在の機能の制約

1.1.1のゲームパッド入力はXInput対象・最大4台です。DirectInput専用機器、振動、Action Mappingは未提供です。実機の全機種保証は行っていません。

物理のConstraint・Character Controller・1 Entity内の複数Collider、Audioの3D空間化・ストリーミングは未提供です。各バージョンの変更点に詳しい制約を記載しています。

インストールとバージョン管理

ランチャーはユーザーのLocalAppData配下へ導入します。エンジン本体の保存先はランチャーから指定できます。旧バージョンと既存プロジェクトの関連付けを、自動的に新バージョンへ置き換えることはありません。

ダウンロードできないとき

「準備中」のファイルはまだサーバーに公開されていません。通信エラーの場合は再読み込みをお試しください。入手したファイルのSHA-256はPowerShellの Get-FileHash コマンドで確認できます。
