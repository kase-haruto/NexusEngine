# NexusEngine Launcher 1.2.0

2026-11-16 / Windows x64

## 新機能

- 「プロジェクト」に「エンジンを変更…」を追加。既存プロジェクトから、インストール・登録済みの別バージョンのエンジンを選択できます。
- 「互換性を確認」で、変更前後のエンジン、Level形式、移行の制約を確認できます。確認した計画と終了・再ビルドの了承がある場合だけ適用できます。移行先を選び直すと再確認が必要です。
- 適用前に元のプロジェクト設定と復旧記録を保存します。「復旧ファイルから元に戻す…」から元のエンジン設定へ戻せます。レビュー後のファイル変更や、復旧後に上書きされる編集がある場合は適用・復旧を拒否します。
- ウィンドウ幅が狭い場合、プロジェクトの操作ボタンを折り返して表示します。
- ランチャー更新一覧に、このバージョンの変更点を表示します。

## 更新方法と使い方

1. 既存ランチャーの「ランチャーの管理」→「ランチャーのバージョン一覧を取得」から1.2.0を選び、「選択したランチャーをインストール」を押します。Webサイトから新しいlauncherSetup.exeを取得して実行することもできます。
2. 移行先のエンジンをインストールします。
3. 「プロジェクト」で対象を選び、「エンジンを変更…」→移行先を選択→「互換性を確認」を押します。
4. 対象のEditor / Runtimeを終了し、確認欄にチェックして「確認した変更を適用」を押します。
5. 一覧の「開く」から移行先のSDKで再ビルドし、動作を確認します。

## 互換性と制約

- ランチャーのみの更新です。公開済みエンジンSDKのバージョン・内容は変更しません。旧ランチャー・SDKの配布も保持します。
- 移行処理はプロジェクト設定のエンジン要求を変更します。Level・Asset・Sourceの自動変換やゲーム固有APIの修正は行いません。
- 形式の事前検査が通っても、API・インポーター・ゲーム固有データの互換性を保証しません。ビルドや動作に問題がある場合はコードの修正、または元の設定への復旧が必要です。
- 復旧は元の設定ファイルだけが対象です。移行後のソースやアセットの編集は巻き戻しません。
- 検証は1.2.0→1.3.0のSDK移行と復旧を含みます。すべてのユーザープロジェクト・DPIでの動作は未検証です。
