# エディタとランチャーの操作改善

Viewport右上の設定は、DPI倍率の端数と子Windowの自動高さ計測中のScrollbarによって折り返さないようにしています。Viewport自体が狭い場合の折り返しは維持します。

プロジェクト起動時は、同じ内容の`Nexus.Engine.local.props`を再保存しません。不要な再コンパイルを防ぎ、エディタの出力はプロジェクトの`Build/Logs/Editor-*.log`へ分離します。ランチャーには起動中の説明と進行表示が出ます。

新規作成画面のテンプレートは「空のプロジェクト」と「基本の3Dプロジェクト」です。空のシーンにはEntityを配置しません。基本の3DにはCamera、Sky、Cube、Directional Lightを配置します。開発Backend別のサンプルはCLIのテンプレートIDで引き続き作成できます。既存プロジェクトのシーンは変更しません。古いSDKのテンプレート内容は、そのSDKのものが使われます。

Reload C++はAgentが利用不可、処理待ち、リロード中などの場合に無効表示になります。ツールバーのNative状態テキストは表示しません。

## ランチャー自身のインストール・更新

「ランチャーの管理」でバージョン一覧を取得し、版を選んで「選択したランチャーをインストール」を押します。SetupのサイズとSHA-256を検証してから起動し、現在のランチャーを閉じます。Setupは終了を待ってから表示され、従来と同じインストール画面で版別フォルダーへ導入します。

配布物の生成には`Project/Tools/Project/Build-Distribution.ps1`の`-LauncherVersion`でランチャーの版を指定します。`-CatalogUrl`を指定すると、その隣の`launcher-releases.json`を更新一覧として設定します。別のURLは`-LauncherCatalogUrl`で指定できます。

サイトのビルドは、検証済みの公開Setupから`launcher-releases.json`を生成します。公開時にはバージョン情報も保持します。異なるSetupへ同じ版を付けるとサイトのビルドで拒否します。版情報がない旧SetupはSHA-256の先頭を版識別子に使って保持します。

ソースの変更だけではインストール済みのエディタやランチャーへ反映されません。実際の配布には新しいSDK、Setup、更新一覧の公開が必要です。
