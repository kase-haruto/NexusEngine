# NexusEngine Launcher 1.3.2

2026-11-18 / Windows x64。Engine 1.4.1の別Runtime Curve previewに対応したProjectToolを同梱します。

1.3.1の変更履歴が文字列ではなくPowerShell付加情報付きobjectとなる不具合を修正しました。Web/Launcher catalogの履歴も文字列へ正常化し、旧Launcherから更新一覧を取得できるようにしました。生成時にobjectを拒否する検査を追加しています。

Engine SDKは1.4.1のままです。旧SDKと公開済みSetupは差し替えずに保持します。既存Projectの関連付けは自動変更しません。Launcherの管理画面かサイトから1.3.2を取得してください。

[1.4.1検証記録](Release-1.4.1-Verification.md)も参照してください。
