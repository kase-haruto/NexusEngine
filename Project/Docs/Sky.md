# シーンの空

空は Entity に付けた `SkyRendererComponent` で指定します。
新規プロジェクトの Blank / Basic3D テンプレートには `Sky` Entity を配置しています。
既存シーンでは、エディターの作成メニューから「空を作成」を選ぶか、コンポーネント追加から「空レンダラー」を追加してください。

コンポーネントがない場合や無効な場合はクリア色を表示します。
Properties から有効状態と強度を変更できます。同時に有効にできる空は 1 個です。
コンポーネントはレベルに保存され、Undo/Redo、シーン複製、PIE、ライブコーディングの復元に対応します。

- HDR 環境画像がない場合は、青い天頂から明るい地平線へ変化するプロシージャルな空を描画します。
- 有効な HDR 環境画像がある場合は、環境光と同じ画像・Y 軸回転を背景にも使用します。背景強度は画像の強度とコンポーネントの強度の積です。
- 背景の強度は、GI 無効時の環境光抑制倍率には影響されません。
- 空はカメラの回転に追従し、移動による視差を持ちません。
- 深度は最遠面でテストし、深度バッファには書き込みません。モデルやグリッドは手前に描画されます。
- 空の色はシーンの HDR 描画先へ出力され、通常の露出・トーンマッピングを通ります。

`SkyRendererComponent` は CPU 設定だけを持ち、`RenderSceneExtractor` が描画スナップショットに抽出します。
GPU 資源と描画パスは `GraphicsSystem` が所有する `SkyRenderer` に分離しています。
メッシュ用の `PrimitiveRenderer` は空の GPU 資源や描画処理を持ちません。
エディター、ゲーム、カメラプレビューで同じシーン設定を使用します。
Entity の位置・スケールは背景に影響しません。
カメラのないシーンでは従来どおりクリア色を表示します。

`NexusGraphicsTests.exe --sky` で GPU 描画・読み戻し検証を実行できます。
確認用画像は `Generated/SkyPreview/Default.bmp` と `HDR.bmp` に出力します。
