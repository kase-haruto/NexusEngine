# NexusEngine v1.0.0

現在のソースを固定した、Windows x64 / Release向けのInstalled SDK初回パッケージです。

- Editor、Runtime、SDKライブラリ、ヘッダー、シェーダー、テンプレートを含みます。
- Blank / Basic 3Dテンプレートから独立したC++プロジェクトを作成できます。
- ランチャーでバージョン・変更点・配布元・保存先を確認して導入できます。
- エンジンの識別情報とSHA-256 inventoryを検証し、他バージョンと共存できます。
- ランチャーのバージョン取得欄と一覧のレイアウトを修正しました。

SDK内部のバージョンは`1.0.0`、IDは`nexus`、構成は`Release`です。
生成したC++プロジェクトのビルドにはVisual Studio C++ v145ツールとWindows SDKが必要です。
ローカル配布一覧と実際のZIPを生成します。Cloudflareへの公開状態とは区別してください。
