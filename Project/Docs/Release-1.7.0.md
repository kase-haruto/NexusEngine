# NexusEngine 1.7.0

Windows x64 / Release / MT / MSVC v145。

- Content BrowserのSourceフォルダからC#とC++を作成し、生成されたファイルを一覧で選択できます。C#、C++、ヘッダは従来のMaterial Symbolsの形とファイル名で区別できます。
- Source一覧からプロジェクトのビルドを開始し、コンパイル中、成功、失敗とエラー詳細を確認できます。
- ファイルの右クリックからアタッチ先のオブジェクト名を確認し、登録された型を選んで追加できます。アタッチ先が未選択の場合や、現在の型一覧にアタッチ可能な型がない場合は画面に理由を表示します。
- 新規Behaviourの型を読み込むにはエディタの再起動が必要です。再起動後はシーンのオブジェクトを選択してください。通常クラスなどをアタッチするには専用の型登録が必要です。

既存プロジェクトで使う場合は1.7.0 SDKを選択し、プロジェクトを再ビルドしてください。
