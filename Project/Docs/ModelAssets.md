# Entityへのモデル割り当て

EditorApplication::PrepareAssetsは、モデルの読み込み、描画データの統合、GPU資源の準備をバックグラウンドで実行する。描画側は準備済みの範囲だけを使用し、完了した要求が現在の要求と一致する場合に反映する。

ModelAssetLibraryのコピーは、不変なCPUモデルと進行中の読み込みを共有する。同じ参照への同時要求は一つの読み込み結果を利用する。サムネイル用に読み込んだモデルや、要求変更によって描画への反映が取り消されたモデルも、後続の割り当てで再利用できる。

Retainは未使用の描画用Variantを取り除くが、CPUモデルは保持する。Entityからモデルを外して再アタッチしても、モデルファイルの読み込みや解析を繰り返さない。組み込み形状も同じキャッシュを使う。GPU資源は従来どおり使用中の資源を再利用し、解放済みの場合はCPUキャッシュから再作成する。

キャッシュの寿命は元のライブラリとそのコピーがすべて破棄されるまで。使用したCPUモデルを保持するため、その分のメモリを消費する。ファイルの外部変更による自動再読み込みは行わない。

ModelとResolveは必要なら読み込み完了を待つため、実行中のEditorではWorkerから呼ぶ。UI側のFindModelは未完了ならnullptrを返し、ファイル読み込みや完了待ちを行わない。共有対象はSourceキャッシュであり、描画snapshotやVariantは各コピーで独立して準備する。

失敗した読み込みはキャッシュから除外し、次の要求で再試行できる。現在の要求を自動再試行するかどうかは呼び出し側が制御する。

Project/Tests/AssetMemoryTests.inlで再割り当て、サムネイルからの共有、同時要求、失敗後の再試行、描画snapshotの独立性を検証する。NexusEditorTests.exeから実行できる。
