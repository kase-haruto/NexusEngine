# Content Browserからソースを作成する

ゲームプロジェクトをEditorで開き、Content Browserの空白部分・フォルダ・ソースを右クリックして「作成」を開きます。Assets表示からも同じ作成ダイアログを利用できます。

- C# スクリプト: ScriptBehaviourを継承する.csとLifecycleの空実装を生成します。
- C++ Behaviour: Entity Behaviourの.h/.cppと、既存Native Moduleへの登録処理を生成します。

ツールバーの「＋」からも「作成」を開けます。Source上で保存先フォルダを開いてから作成に進むと、そのフォルダを所有するモジュールと相対ディレクトリが初期入力されます。クラス名は英字から始まる英数字・アンダースコアで指定します。拡張子は自動で付きます。

対応する言語のモジュールがない場合は「Project画面を開く」から追加します。Sourceファイルはゲームプロジェクトのビルド対象へ所属する必要があるため、Engine単体を開いた状態では作成できません。

「作成」は既存のAdd-GameSource処理を非同期で実行します。成功すると生成先を表示して新しいファイルを選択します。「作成後にコードエディタで開く」が有効なら、既存のSourceCodeEditor設定でファイルを開きます。一覧にはファイル名と、Google Fonts Material SymbolsのC#、C++実装、ヘッダそれぞれの異なる形のアイコンが表示されます。

Source一覧の「プロジェクトをビルド」でコンパイルします。進行状況と失敗時のエラーを同じブラウザで確認できます。新しいBehaviourの型を読み込むにはエディタを開き直してください。シーンのオブジェクトを選択し、一覧のファイルを右クリックして「選択中のオブジェクトにアタッチ」を開きます。アタッチ先の名前を確認してから型を選ぶと、通常のシーン編集履歴に追加されます。

C#のBehaviourはScriptBehaviourテンプレートとビルド時のManagedメタデータ、C++のBehaviourは生成される.h/.cppとNative Moduleの登録情報を使います。通常クラス、ヘッダ単体、実装ファイル単体にも生成テンプレートがあります。アタッチするには、ファイルと関連付く追加可能な型が現在の型レジストリに必要です。Play中のReload C#と、対応環境限定のReload C++は既存の実行時開発ツールです。

生成失敗はBrowserと既存のProjectログへ表示します。C++登録ファイルが手動変更されているなど、既存generatorが安全に拡張できない場合はそのgeneratorの検証結果に従い、部分的な登録や既存コードの置換を行いません。

検証はContentSourceCreationIntegration（右クリック、両言語の作成ダイアログ、Module選択、一覧更新、Open callback、重複・不正名・busy拒否、再構成時のcallback寿命）とHybridGeneration.Tests.ps1（実C#/C++生成、登録、既存コードの保護）で行います。
