# 衝突レイヤー

Collider（Colliderなしの旧EntityではRigidBody）の所属レイヤーと、Project全体の衝突マトリクスを使用します。個別Colliderのmaskで接触を除外する仕組みは使用しません。Raycastの検索用maskは引き続き使用できます。

## Inspector

Collision Layerで名前付きレイヤーを選びます。衝突相手は共通マトリクスから計算した読み取り専用の要約です。「衝突レイヤー設定を開く」で選択中の所属を共通画面へ引き継ぎます。

## 共通設定画面

編集メニュー → Physics / 衝突レイヤー、またはウィンドウメニューから開きます。

- 左：レイヤー一覧、検索、追加。
- 中央：定義済みと現在のレベルで使用中のレイヤーだけを並べた三角形マトリクス。同じ組合せは一度だけ表示します。対角線は同じレイヤー同士の衝突です。
- 右：選択したレイヤーの名前、現在のレベルでの使用数、名前変更、削除・所属移行、衝突相手の詳細一覧。

マトリクスと詳細一覧は同じデータを編集します。ホバーで行・列と対象pairを確認できます。変更はConfigへ自動保存します。画面のUndo/Redoボタン、またはこの画面にフォーカスがあるときのCtrl+Z/Ctrl+Yで取り消し・再適用できます。履歴はLevelの切替で消えません。通常のオブジェクト編集履歴とは独立しています。

Defaultは削除・名前変更できません。名前は重複不可で、制御文字や前後の空白は使用できません。

## 削除と移行

削除前に現在のレベルで使用しているオブジェクトと移行先を確認します。保存済みレベルも含め、古い所属IDは移行先として解決されます。Raycastも移行先のレイヤーで検索できます。

古いLevel内のIDが将来別の意味へ変化しないよう、削除したIDは再利用しません。使用できるIDは合計32個（Defaultを含む）です。削除はUndoで戻せます。Levelファイルを一括上書きする操作は行いません。

## 保存と実行

ProjectのConfigディレクトリの`PhysicsLayers.settings`に名前・マトリクス・削除IDの移行先を保存します。独自のConfigパスにも対応します。エディタ再起動、Play、別レベルへの遷移、単体Runtimeは同じファイルを使用します。実行中の設定編集は無効です。

保存失敗・重複名・不正な対称性を検出した場合は現在の設定を維持し、画面に理由を表示します。他のEditorがファイルを変更した場合は古い編集やUndoで上書きせず、Editorの再起動を案内します。

Levelはv14で保存し、衝突ルールはLevel内に保存しません。旧v1～13は読めますが、新しいProject共通設定が優先します。旧`collisionMask`値は保存互換のため残りますが、衝突可否には影響しません。
